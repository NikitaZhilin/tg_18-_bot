# Как играть

## Главное меню

Наберите `/start`. Меню открывается одним сообщением и обновляется на месте.

| Кнопка | Что делает |
|---|---|
| ▶️ Вернуться к карточке | Есть, только если карточка не закрыта |
| 🎲 Случайная карточка | Бот выбирает из уровней, включённых в настройках |
| 🃏 Выбрать уровень | Уровень → интенсивность (для 3–4) → тип карточки |
| 🎭 Правда или действие | Уровень и интенсивность, дальше каждый выбирает «💬 Правда» или «🎯 Действие» |
| 🍑 Анал: … | Для обоих / только для неё / только для него / выключен |
| 🔞 Экстрим: ✅ вкл / 🚫 выкл | Переключатель Экстрима; когда включён, рядом кнопка «🔞 Экстрим» |
| 🎁 Желания (N) | Сохранённые купоны |
| ⭐ Избранное (N) | Понравившиеся карточки — нажмите, чтобы сыграть снова |
| ⚙️ Настройки | Уровни для случайной карточки, 🧸 игрушки и реквизит, 🚧 границы на сегодня |
| 🛠 Админка | Только владельцам |
| ⏹ Закончить игру | С подтверждением; бот показывает итог вечера: сколько карточек, по уровням, отказы и штрафы |

Если игры ещё нет или её закончили, любая кнопка с карточками сама начинает новую. Новая игра
в том же чате берёт из прошлой уровни, игрушки, границы, «🍑 Анал», «🔞 Экстрим» и неиспользованные
желания (желания — если играют те же люди). Избранное хранится для чата всегда.

## Уровни и интенсивность

- 💬 **Флирт** — разговоры, игрушки, фантазии, лёгкое раздевание.
- 🔥 **Разогрев** — ласки и прелюдия без секса.
- ❤️‍🔥 **Секс** — позы, стимуляция, игрушки.
- ⛓ **БДСМ** — связывание, шлепки, плётка, игра во власть.

На уровнях 3 и 4 выбирается интенсивность: 🌿 мягко, 🔥 средне, 💥 жёстко.

Типы карточек: 💬 вопрос, 🎯 задание, 🛏 поза, 🎁 желание. Желание — это купон: бот сохраняет его,
и владелец использует, когда захочет.

## Карточка

- **✅ Сделали** — очередь переходит к партнёру.
- **🙅 Отказ → штраф** — вместо карточки выпадает штраф того же уровня. От штрафа отказаться
  нельзя, на нём только «✅ Выполнено». Когда штрафы на уровне закончились, они начинают повторяться.
- **⭐ В избранное** — сохранить карточку, чтобы потом сыграть её снова (повторное нажатие убирает).
- **🚫 Убрать навсегда** — плохая карточка: она пропадает из игры и уходит владельцу
  в «Админка → Карточки на доработке».
- **⏱ Запустить таймер** — если в карточке есть время; бот напишет, когда оно выйдет.
- **🏠 Меню** — карточка остаётся открытой, к ней можно вернуться.

Под карточкой бот перечисляет нужные игрушки («🧸 Понадобится»).

## Правда или действие

Выберите уровень (и интенсивность для 3–4). Бот пишет, чья очередь, и предлагает «💬 Правда» —
откровенный вопрос — или «🎯 Действие» — задание. После «Сделали» или штрафа тот же выбор получает
партнёр. Если вопросы на выбранной интенсивности закончились, бот берёт вопрос того же уровня
другой интенсивности.

## 🍑 Анал

Переключатель действует до конца игры.

- **✅ Обоим** — выпадает всё.
- **👩 Только для неё** — скрыты карточки, где анал для него (например, страпон).
- **👨 Только для него** — скрыты карточки, где анал явно для неё.
- **🚫 Выключен** — скрыто всё, где анал обязателен: пробки, крюк, анилингус, двойное.

Карточки «вагинально или анально» остаются: там выбираете сами.

## 🔞 Экстрим

Самые жёсткие карточки 4-го уровня: крюк с верёвкой и кляпом, надувная пробка до предела,
фистинг, бужи, связывание, принудительные оргазмы и другое.

- **Включён** (по умолчанию в каждой новой игре): карточки Экстрима могут выпасть в случайной,
  на 4-м уровне «Жёстко» и в «Правде или действии»; кнопка «🔞 Экстрим» выдаёт только их.
- **Выключен:** они не выпадают нигде.

## Настройки

- **🎲 Уровни для случайной** — из каких уровней берёт карточки «Случайная».
- **🧸 Игрушки и реквизит** — ваши игрушки отмечены с начала игры; отметьте «нет» то, чего
  сегодня нет под рукой. Частота «редко / иногда / часто» влияет на случайные бонусы.
- **🚧 Границы на сегодня** — исключить связывание, шлепки, воск, повязку, руку на шее,
  уретральные игры, электростимуляцию и т. д.

## Игра в группе (с разных телефонов)

1. Создайте группу только из тех, кто играет, и добавьте туда бота.
2. Наберите в группе `/start`. Бот попросит пароль — ответьте на его сообщение паролем.
   Сообщение с паролем бот сразу удаляет. Пароль один раз задаёт владелец:
   «🛠 Админка → 🔑 Пароль для групп» в личке с ботом.
3. Каждый игрок нажимает «🙋 Я играю». Когда набралось двое (или трое в игре на троих), игра
   начинается; бот называет игроков их именами в Telegram.
4. Кнопки нажимает только тот, чья очередь. Посторонний получает «Вы не участвуете в этой игре».
5. Если в группе есть кто-то кроме игроков, карточки не показываются.
6. «⏹ Закончить игру» освобождает места: в следующий раз игроки снова жмут «🙋 Я играю».

Игра в группе отдельная от игры в личке, со своими настройками.

## Игра на троих

Скрытый режим, его не видно в меню и справке.

- Включает владелец: «🛠 Админка → 👥 Игра на троих → ✅ Включить».
- Работает только в открытой паролем группе: ждут троих, каждый жмёт «🙋 Я играю».
- Очередь идёт по кругу в порядке входа.
- Выпадает только отдельная колода «На троих»: 60 заданий и поз (по 15 на уровень), 24 вопроса,
  12 штрафов. Роли в тексте — «он», «жена», «гостья». Экстрима в этом режиме нет.
- Если переключить режим, игра в группе начнётся заново. Личка не меняется.

## Безопасность

- `/stopword` или кнопка стоп-слова мгновенно останавливает игру, таймеры отменяются.
- В карточках БДСМ с кляпом сигнал вместо стоп-слова — бросить ключи из руки.
- Жёсткие запреты зашиты в бота: никаких карточек с удушением, кровью, копро и другими
  запрещёнными тегами (см. [content.md](content.md)).

## Команды

`/start` — меню, `/help` — справка, `/stopword` — стоп. Владельцам: `/admin`, `/status`.
Если кнопка в старом сообщении отвечает «кнопка устарела», наберите `/start`.
