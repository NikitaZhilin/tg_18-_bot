# Карточки

## Колоды

Карточки лежат в двух CSV-файлах и загружаются в базу при каждом старте бота
(`app/main.py → import_startup_content`). Правки, сделанные в админке, импорт не затирает: если
встроенная карточка изменилась и в базе, и в файле, появляется конфликт в «Админка → Конфликты».

| Колода | Файл | Коллекция | Где выпадает |
|---|---|---|---|
| Основная | `content/cards.csv` | `base_tasks`, позы — `kamasutra_inspired_poses` | Игра вдвоём (личка и группа) |
| На троих | `content/cards.csv` | `threesome` | Только в игре на троих |
| Экстрим | `content/restricted_cards.csv` | `restricted_content` | Вдвоём, когда «🔞 Экстрим» включён |

Выключенные карточки (`is_enabled=0`) остаются в файлах — так их история не теряется, а
`external_id` никогда не переиспользуется.

## Принципы текста

- **Тут и сейчас.** Никаких долгих заданий не про секс: телефон, интернет, игры на угадывание,
  душ, еда, переход в другую комнату — не используются.
- **Простой текст без заголовков.** Не пишем «Порядок:», «Контекст:», «Ответьте:» и т. п.
  Абзацы: что делать → чем закончить. Штраф — один абзац.
- **Без лишних оговорок.** Никаких «спросите „можно?“ перед каждым шагом», гигиены, «два пальца
  запаса» — пара это знает. Описания игрушек под карточкой тоже пустые.
- **Для обоих.** Где можно, роли нейтральные: «активный / принимающий», «ведущий / ведомый»,
  «если принимает она — …, если он — …». Где практика задана предпочтениями пары, роли названы
  прямо.
- **Вопросы на «ты».** Отвечает тот, кто вытянул карточку; второй абзац — что делает партнёр.
- **Слово «ход» не используется** (тест), вместо него «очередь».
- **Таймер.** Если у карточки есть `timer_seconds`, время названо в тексте («три минуты по таймеру»).

## Формат CSV

Колонки: `external_id, level, category, intensity, title, text, required_items, item_mode,
timer_seconds, risk_tags, avoid_if_tags, collection, review_status, is_enabled,
aftercare_required, pose_family, pose_difficulty, space_required, body_load, notes`.

- `level` 1–4; `intensity` `light|medium|hard` (на 1–2 всегда `light`).
- `category` `task|question|pose|desire|penalty`.
- `required_items` — коды через запятую, `item_mode=required`: карточка выпадает, только если
  все предметы включены в игре.
- `review_status=approved` и `is_enabled=1` — карточка в игре.
- `pose_family` для поз — из `app/labels.py → POSE_FAMILY_NAMES` (иначе XLSX-импорт откажет).
- `title` уникален во всех файлах.

## Теги

`risk_tags` решают, когда карточка скрыта.

| Тег | Кто использует |
|---|---|
| `restraint`, `impact`, `wax`, `sensory_deprivation`, `food`, `toys`, `neck_play`, `urethral_play`, `estim` | «🚧 Границы на сегодня» |
| `anal`, `anal_her`, `anal_him` | «🍑 Анал»: выкл — скрывает `anal`; только для неё — `anal_him`; только для него — `anal_her` |
| `power_exchange`, `fisting`, `advanced_insertion`, … | Информационные, для админки и экспорта |

`app/domain.py → FORBIDDEN_RISK_TAGS` — жёсткие запреты (удушение, кровь, копро, травма, фиксация
без быстрого освобождения и др.): карточка с таким тегом при импорте сразу выключается. Поэтому
теги границ — отдельные, а не из этого списка.

## Реквизит

Таблица `items` (миграции 001, 019). `default_owned=1` — игрушки пары включены в каждой новой игре:
фаллосы (большой, с нагревом, мини), щупальце, вибратор, вакуумный стимулятор, плётка, верёвка,
кляп, пробки S/M/L, надувная пробка, вакуумные насадки, бужи, кольцо, насадка, мастурбатор,
расширитель, анальный крюк, электростимулятор, свеча для массажа, страпон, лубрикант, повязка,
зажимы на соски. Описания (`usage_text`) пустые — под карточкой показываются только названия.

## Как добавить или поправить карточку

- **Одну-две** — «🛠 Админка → Добавить карточку» или каталог.
- **Много** — «Экспорт XLSX», правка в Excel, «Импорт XLSX».
- **В репозитории** — правка CSV и PR. Перед PR:

```bash
python scripts/audit_card_content.py      # заголовки, таймеры, дубли, активность в позах
python -m pytest tests/test_content_clarity.py tests/test_content_importer.py
```

Тесты фиксируют числа карточек (`test_content_importer`, `test_admin_export`) — при добавлении
обновите их. Если карточка уже правилась в админке на сервере, новый текст из CSV придёт как
конфликт.
