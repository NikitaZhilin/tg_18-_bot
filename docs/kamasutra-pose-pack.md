# Пак поз в стиле камасутры

## Назначение

Этот документ описывает стартовый набор `pose`-карточек для бота. Формат намеренно неграфичный: карточка дает название, настроение, сложность, пространство, ограничения и safety-заметки, но не расписывает анатомические инструкции.

Коллекция:

```text
kamasutra_inspired_poses
```

Категория:

```text
pose
```

## Поля

```text
external_id
level
category
intensity
title
text
pose_family
pose_difficulty
space_required
body_load
required_items
timer_seconds
safety_level
risk_tags
requires_both_opt_in
requires_safeword_check
aftercare_required
review_status
is_enabled
notes
```

## Правила импорта

Для всех карточек из этого пака:

```text
category = pose
collection = kamasutra_inspired_poses
review_status = needs_review
is_enabled = 0
```

Включать в игру только после ручного просмотра.

Для `level = 4` или `intensity = hard`:

```text
requires_both_opt_in = 1
requires_safeword_check = 1
aftercare_required = 1
```

## Что не включено

В пак не входят:

- дыхательный контроль;
- травмирующие практики;
- фиксация без быстрого освобождения;
- публичные сценарии;
- фото/видео без согласия;
- сценарии с опьянением.
