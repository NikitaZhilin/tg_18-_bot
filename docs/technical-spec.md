# Техническое задание v5 (октябрь 2026)

Правила поведения бота. Как этим пользоваться — в [user-guide.md](user-guide.md), как устроено —
в [architecture.md](architecture.md). Предыдущее ТЗ — [archive/technical-spec-v4-2026-07.md](archive/technical-spec-v4-2026-07.md).

## 1. Назначение

Приватная карточная игра для взрослой пары и, в скрытом режиме, для троих. Бот выдаёт вопросы,
задания, позы, желания и штрафы, ведёт очередь и таймеры, учитывает игрушки и границы.

## 2. Где и кто играет

1. **Личка с ботом.** Доступ — `ALLOWED_TELEGRAM_USER_IDS`. Оба игровых слота — хозяин чата
   (один телефон на двоих), имена слотов — `PLAYER_1_NAME`, `PLAYER_2_NAME`.
2. **Группа.** Открывается паролем. Пароль задаёт админ в админке, хранится только PBKDF2-хеш.
   Пароль вводится ответом на сообщение бота, сообщение удаляется. После открытия каждый игрок
   нажимает «🙋 Я играю»; игроки — первые 2 (или 3 на троих) нажавших, в этом порядке, с их
   именами из Telegram. Остальные участники не могут нажимать игровые кнопки.
3. В группе, где людей больше, чем игроков, карточки не выдаются.
4. Бота может добавить в группу кто угодно; без пароля в ней ничего не работает.
5. Завершение игры в группе освобождает места.
6. **Игра на троих** (ЖМЖ) включается только админом, работает только в группе, ждёт троих игроков,
   использует только колоду `threesome`. Смена режима начинает игру в группе заново.

## 3. Игровой процесс

1. Любая кнопка, выдающая карточку, сама открывает игру, если её нет.
2. Карточку может взять и закрыть только игрок, чья очередь. Очередь идёт по кругу после
   «Сделали» или выполненного штрафа.
3. Режимы: случайная (по включённым уровням), выбор уровня → интенсивности (3–4) → категории,
   «Правда или действие» (вопрос или задание выбранного уровня; при нехватке вопросов — другая
   интенсивность того же уровня; после закрытия карточки выбор получает следующий игрок).
4. **Отказ → штраф:** карточка закрывается как пропущенная, тот же игрок получает штраф того же
   уровня (при нехватке — уровня ниже, затем с повторами). От штрафа отказаться нельзя.
   Штрафы выпадают только при отказе.
5. **Убрать карточку навсегда:** карточка выключается, уходит в «Карточки на доработку», игроку
   выдаётся замена.
6. Повторов внутри одной игры нет (кроме штрафов).
7. Таймер стартует по кнопке и приходит сообщением по окончании.
8. Желания сохраняются как купоны владельца и используются из меню.

## 4. Фильтры

1. **Реквизит:** карточка с `required_items` выпадает, только если все предметы включены в игре.
   Игрушки пары (`default_owned`) включены с начала каждой игры.
2. **Границы на сегодня** скрывают карточки с выбранными тегами.
3. **🍑 Анал** (на игру): обоим / только для неё / только для него / выключен — через теги
   `anal`, `anal_her`, `anal_him`. Сохранение границ режим не сбрасывает.
4. **🔞 Экстрим** (на игру, по умолчанию включён): включён — карточки `restricted_content`
   участвуют в любой выдаче, отдельная кнопка выдаёт только их; выключен — не выдаются нигде.
   В игре на троих Экстрима нет.
5. `FORBIDDEN_RISK_TAGS` (удушение, кровь, копро, травма и др.) — карточка выключается при импорте.

## 5. Контент

Правила текста и формат — [content.md](content.md). Кратко: «тут и сейчас», простой текст без
заголовков разделов, без лишних оговорок, роли для обоих, вопросы на «ты».

## 6. Админка

Только для `ADMIN_TELEGRAM_USER_IDS`: добавление и каталог карточек, проверка и доработка,
каталог реквизита, жалобы игроков, конфликты обновлений, импорт и экспорт XLSX,
«🔑 Пароль для групп», «👥 Игра на троих». Версии карточек сохраняются, их можно восстановить.

## 7. Надёжность

1. Состояние игры, диалогов админки и настроек хранится в SQLite и переживает перезапуск.
2. Кнопки старых карточек не действуют на текущую.
3. Ошибки обработчиков — короткое сообщение игроку и отчёт владельцам (не чаще раза в 10 минут).
4. Деплой: CI → проверка на сервере → бэкап → перезапуск → heartbeat → откат при неудаче.
5. Бэкап ежедневно и копия владельцам в Telegram раз в неделю.
6. Ежедневная проверка сервера только на чтение, вывод без ID и IP.

## 8. Приёмка

- `python scripts/audit_card_content.py` — без ошибок.
- `python -m pytest` — все тесты зелёные (сценарии: личка, группа с паролем и «Я играю», игра на
  троих, отказ и штраф, «Правда или действие», анал, Экстрим, импорт и экспорт).
- Деплой и проверка сервера в GitHub Actions — успешны.
