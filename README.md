# tg_18_bot

Приватный Telegram-бот: карточная игра для взрослой пары — вопросы, задания, позы, желания
и штрафы четырёх уровней. Можно играть с одного телефона в личке с ботом или с разных
телефонов в общей группе, а в скрытом режиме — втроём.

## Что умеет

- **Четыре уровня:** 💬 Флирт, 🔥 Разогрев, ❤️‍🔥 Секс, ⛓ БДСМ. На уровнях 3–4 есть интенсивность:
  мягко, средне, жёстко.
- **Режимы:** 🎲 случайная карточка, 🃏 выбор уровня и типа, 🎭 «Правда или действие».
- **Отказ → штраф:** от любой карточки можно отказаться, но тогда выпадает штраф того же уровня.
  От штрафа отказаться нельзя.
- **🍑 Анал:** для обоих, только для неё, только для него или выключен — на текущую игру.
- **🔞 Экстрим:** самые жёсткие карточки, включаются одной кнопкой. Когда Экстрим включён,
  его карточки попадаются в любом режиме.
- **Игрушки пары** включены по умолчанию; карточки с отсутствующим реквизитом не выпадают.
- **Группы:** открываются паролем, игроки заходят кнопкой «🙋 Я играю».
- **Игра на троих (ЖМЖ):** скрытый режим с отдельной колодой; включает админ, работает только
  в группе.
- **Админка в Telegram:** каталог карточек и реквизита, XLSX-экспорт и импорт, конфликты обновлений,
  карточки на доработке, пароль для групп, переключатель игры на троих.
- **Эксплуатация:** CI/CD с откатом, ежедневный бэкап, еженедельная копия базы владельцам в Telegram,
  проверка сервера, отчёты об ошибках владельцам.

## Быстрый старт (локально)

```bash
python -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
cp .env.example .env            # заполнить BOT_TOKEN и ID, см. ниже
python scripts/smoke_start.py
python scripts/audit_card_content.py
python -m pytest -q
```

Не запускайте бота локально с тем же `BOT_TOKEN`, пока он работает на сервере: Telegram отдаёт
обновления только одному экземпляру.

## Настройки `.env`

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | Токен от @BotFather |
| `ALLOWED_TELEGRAM_USER_IDS` | Кто может играть в личке с ботом (через запятую) |
| `ADMIN_TELEGRAM_USER_IDS` | Владельцы: админка, отчёты об ошибках, еженедельная копия базы |
| `PLAYER_1_NAME`, `PLAYER_2_NAME` | Имена игроков в личке: бот чередует их на одном телефоне |
| `BOT_TIMEZONE` | Часовой пояс, по умолчанию `Europe/Moscow` |
| `DATABASE_PATH`, `DATA_DIR` | Где лежит SQLite |
| `REQUIRE_DAILY_CONSENT` | `true` — экран подтверждения перед первой игрой за день (по умолчанию выключен) |
| `SINGLE_ACCOUNT_TWO_PLAYERS` | Исторический флаг; в личке и так играют вдвоём с одного аккаунта |
| `ADMIN_CONTENT_PASSWORD_SHA256` | Больше не используется: Экстрим включается кнопкой |
| `TELEGRAM_PROXY_URL`, `LOG_LEVEL`, `DRY_RUN`, `ALLOW_UNLISTED_USERS` | Служебные |

Для игры в группе ID второго игрока не нужен: группа открывается паролем, который владелец задаёт
в админке («🔑 Пароль для групп»). В базе хранится только PBKDF2-хеш пароля. Токены, пароли и
Telegram ID в репозиторий не коммитятся — он публичный.

## Команды

- `/start` — меню игры (в группе — пароль и «🙋 Я играю»);
- `/help` — как играть;
- `/stopword` — мгновенно остановить игру;
- `/admin`, `/status` — для владельцев;
- `/reset` — синоним «Закончить игру».

## Деплой

Push в `main` запускает `.github/workflows/ci-deploy.yml`: аудит карточек, тесты, перенос на сервер,
повторная проверка там, бэкап базы, перезапуск и проверку сердцебиения бота. Если проверка не прошла,
сервер возвращается к прежней версии и базе. На pull request выполняются только проверки.
Подробности, таймеры и восстановление — в [docs/operations.md](docs/operations.md).
